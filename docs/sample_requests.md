# Sample API Requests / Responses

Base URL assumed: `http://localhost:8000`

## 1. Upload an image

```bash
curl -X POST http://localhost:8000/api/v1/images \
  -F "file=@/path/to/vehicle_photo.jpg;type=image/jpeg"
```

Response — `202 Accepted`:

```json
{
  "id": "3f1b2c4a-1a2b-4c3d-9e8f-7a6b5c4d3e2f",
  "status": "pending",
  "created_at": "2026-08-08T10:15:00.123456+00:00"
}
```

```bash
curl http://localhost:8000/api/v1/images/3f1b2c4a-1a2b-4c3d-9e8f-7a6b5c4d3e2f
```


## 4. Fetch result for a failed job

```bash
curl http://localhost:8000/api/v1/images/<id>/result
```

Response — `409 Conflict`:

```json
{ "detail": "processing failed: could not decode image: cannot identify image file '...'" }
```

## 5. List recent images (optionally filter by status)

```bash
curl "http://localhost:8000/api/v1/images?status=failed&limit=20"
```

Response — `200 OK`:

```json
{
  "items": [
    {
      "id": "3f1b2c4a-1a2b-4c3d-9e8f-7a6b5c4d3e2f",
      "original_filename": "corrupt_upload.jpg",
      "status": "failed",
      "created_at": "2026-08-08T10:12:00.000000+00:00"
    }
  ],
  "limit": 20,
  "offset": 0
}
```

## 6. Rejected upload (wrong content type)

```bash
curl -X POST http://localhost:8000/api/v1/images -F "file=@notes.txt;type=text/plain"
```

Response — `415 Unsupported Media Type`:

```json
{ "detail": "unsupported content type 'text/plain'. Allowed: ['image/jpeg', 'image/png', 'image/webp']" }
```

## 7. Health check

```bash
curl http://localhost:8000/health
```

```json
{ "status": "ok" }
```

Interactive docs are also available at `http://localhost:8000/docs` (Swagger UI, auto-generated by FastAPI).
